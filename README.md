# cv-movil

Aplicación móvil de Hoja de Vida hecha con React Native y Expo.
Taller SENA - Tecnólogo en Análisis y Desarrollo de Software.

## Pantallas
- Datos personales
- Estudios (los que están en curso se resaltan con una insignia morada)
- Experiencia laboral
- Hobbies

## Ejecutar
npm install
npx expo start
